# 🎯 Program Vision

The BS in Cybersecurity prepares graduates to design, build, protect, investigate, and govern secure digital systems across conventional computing, cloud platforms, artificial intelligence, autonomous systems, critical infrastructure, connected devices, and emerging technologies.

The program combines:

- Computer Science
- Mathematics
- Cybersecurity
- Artificial Intelligence
- Cloud & Distributed Computing
- Software Engineering
- Cryptography
- Digital Forensics
- Cyber Defense
- Privacy
- Governance & Risk
- Quantum-Resistant Security
- Autonomous & Agentic System Security
- Cyber-Physical Systems

The curriculum is intentionally divided into two layers:

**Permanent foundation:** mathematics, programming, algorithms, operating systems, networking, architecture, databases, software engineering, cryptography and security principles.

**Evolving security layer:** AI security, cloud-native security, agentic AI, quantum-safe cryptography, autonomous defense, cyber-physical systems, privacy engineering and emerging technologies.

This structure allows the program to remain relevant even when specific technologies change.

# 🎯 PROGRAM'S CORE PHILOSOPHY

The goal is **not** to predict exactly what cybersecurity will look like in 2040.

The goal is to produce graduates who can learn and secure technologies that do not yet exist.

Therefore, the graduate should be able to:

> **Understand → Build → Attack → Detect → Defend → Investigate → Automate → Govern → Research**

# ⭐ FINAL ASSESSMENT

This version is significantly stronger than the original curriculum.

**For 2030:** ★★★★★
**For 2035:** ★★★★★
**For 2040:** ★★★★½

It is not "future-proof" because no curriculum can literally predict 2040.

It is **future-resilient** because the permanent computer-science and cybersecurity foundations remain stable while the advanced layer can evolve.

The most important change is that **AI security, AI-agent security, software/AI supply-chain security, cloud-native security, post-quantum migration, cyber-physical security and autonomous defense are now integrated into the core rather than being treated as afterthoughts.**

That gives this curriculum a much stronger **2030–2040 profile**.
